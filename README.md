# BREACH

A premium brick breaker for iPhone where every level is a rescue against the clock: carve an escape tunnel through a mosaic of thousands of micro-bricks to free a trapped Wisp before the threat reaches it, then watch the structure collapse.

Status: design phase. Read the plan in [docs/GAME_PLAN.md](docs/GAME_PLAN.md).
