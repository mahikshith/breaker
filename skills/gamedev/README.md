# Game-dev skills used to build BREACH

These are copied from github.com/gamedev-skills/awesome-gamedev-agent-skills (Apache-2.0; see LICENSE and NOTICE). Only the skills relevant to a 2D web brick breaker are kept.

Each skill is a folder with a `SKILL.md`, plus optional `references/` and scripts. An agent reads the `SKILL.md` before doing that kind of work. The list of which skill to read for which task is in `AGENTS.md` at the repo root.
