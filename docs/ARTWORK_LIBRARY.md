# Reusable artwork

The permanent artwork folder is [`artwork-library/`](../artwork-library/README.md), at `C:\Users\mahik\Music\Breach\breaker\artwork-library` in this checkout.

Use its [catalogue](../artwork-library/CATALOGUE.md) to open preserved boards, original source images, sprites and character renders. Its [manifest](../artwork-library/manifest.json) records every original location, full SHA256 and size. Carrier Breakout, Relay Raiders / Circuit Breakout, Orbital Breakout / Shutter Forge, Eclipse Rescue, Nix/Tick and earlier character studies are covered. Historical and rejected designs remain available for reference and do not become approved assets by being archived.

After producing new artwork, run `python tools/archive_artwork.py`. It verifies the archive and adds new versions without overwriting older work. Keep the working asset manifests and render scripts at their existing paths; the library is the preserved original, not a second runtime asset pipeline. See the library README for the exact included folders and local-backup limits.
